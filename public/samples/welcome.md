# Welcome to Markdown Viewer

A clean, powerful markdown editor inspired by Typora and Mark Text.

## Getting Started

Open a file from the sidebar, drag-and-drop a `.md` file, or start typing in the editor on the left. The preview updates in real time.

### Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Bold | `Cmd+B` |
| Italic | `Cmd+I` |
| Link | `Cmd+K` |

## Features

- Split-pane editing — editor and preview side-by-side
- GFM support — tables, task lists, strikethrough, footnotes
- Syntax highlighting — all major languages
- Multiple tabs — work on several files at once
- Export — download as HTML or PDF
- Auto-save — changes saved to localStorage automatically
- Dark mode — easy on the eyes
